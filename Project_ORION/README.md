# Project ORION

This directory contains the modular, research-grade autonomous vehicle platform enabling rapid experimentation in perception, localization, planning, control, and intelligent decision-making.

## Directory Structure

- **docs/** - Documentation including vision, requirements, architecture, decisions, roadmap, meetings, and research papers
- **diagrams/** - Architecture and system diagrams
- **simulation/** - Simulation environments and tools
- **hardware/** - Hardware specifications and configurations
- **software/** - Core software modules and implementations
- **experiments/** - Experimental configurations and results
- **datasets/** - Training and testing datasets
- **media/** - Images, videos, and multimedia assets
- **references/** - External references and citations
